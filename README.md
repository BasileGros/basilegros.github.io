## Research
My PhD thesis is on Proxy-based Small Inversions, a technique used in Rocq to perform inversion without equality constraints, well suited to dependent programming.
It involves both a theoretical study of the technique and its application, as well as the development of a Rocq plugin automating it, developed using the MetaRocq metaprogramming library.
You can find an experimental version of this pulgin [here](https://github.com/BasileGros/proxy-based-small-inversions).
